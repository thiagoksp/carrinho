# Contributing

Carrinho is not accepting outside code, documentation, data, prompt, design, or
product contributions at this stage.

The repository is public for project review and development transparency, but it is
not open source. See [`LICENSE`](LICENSE).

Before any outside contribution is accepted, the project owner must define a written
contribution process that covers:

- ownership and licensing of contributed work;
- permission to use the contribution in a future commercial product;
- privacy and security expectations;
- no submission of secrets, API keys, receipts, addresses, or personal household data;
- review requirements for food-safety, legal, and platform-compliance claims.

Unsolicited pull requests or patches may be closed without review.
