# Legal and IP checklist

Updated: August 14, 2026.

This document is a project checklist, not legal advice. Consult a qualified lawyer
before relying on any legal strategy for commercialization, outside contributions,
user data, privacy, trademarks, or platform contracts.

## Current decision

Carrinho stays public while it is being reviewed for the Instacart Developer Platform
path. The repository is public for transparency, but it is not open source.

The repository now includes:

- [`LICENSE`](../LICENSE), an all-rights-reserved notice;
- [`CONTRIBUTING.md`](../CONTRIBUTING.md), which says outside contributions are not
  accepted yet;
- a public GitHub description in Canadian English.

## What copyright helps with

Copyright can protect Carrinho's concrete expression, including source code,
documentation, schemas, prompts, tests, text, and project materials.

Copyright does not fully protect the underlying product idea, such as "a grocery agent
that creates meal plans and shopping lists." Someone could independently build a
similar idea with different implementation and materials.

## Public repository rules

- Keep the repository public only while that visibility has a concrete project reason.
- Do not add an open-source license unless the owner explicitly decides to do so.
- Do not accept outside contributions until contribution ownership is defined in
  writing.
- Do not commit secrets, API keys, Instacart credentials, addresses, receipts, phone
  numbers, emails, or private household data.
- Keep generated local outputs and household data ignored by Git.
- Keep external platform claims conservative and evidence-backed.

## Before commercialization

Review these with a qualified professional:

- whether the repository should become private;
- whether the project name needs trademark review;
- whether a company should own the IP rather than an individual;
- contributor agreements or contractor assignment agreements;
- terms of use;
- privacy policy;
- data retention and deletion rules;
- liability language for dietary, allergy, food-safety, pricing, and checkout claims;
- Instacart, retailer, and LLM-provider contract requirements.
